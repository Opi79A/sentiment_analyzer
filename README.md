## 🧠 Sentiment Analysis Engine
This module provides the "emotional intelligence" for the assistant. 
By using the `TextBlob` library, the system can:
* **Evaluate Polarity**: Measures how positive or negative the text is (from -1.0 to 1.0).
* **Classify Mood**: Categorizes input into **Happy**, **Sad**, or **Neutral**.
* **Provide Feedback**: Helps in understanding the tone of recorded voice notes.
